Privacy Policy

What If Thinkers Uploader · Last updated: November 20, 2026

What If Thinkers Uploader ("the app") is a private tool used only by the owner of the What If Thinkers YouTube channel to upload that channel's own videos. This policy explains what Google user data the app accesses and how it is handled.

Data the app accesses

When the channel owner signs in with Google, the app requests these YouTube permissions:

  • youtube.upload: to upload videos and set their thumbnails.
  • youtube.force-ssl: to upload subtitle files and read the name of the signed-in channel.

The app does not request or read email addresses, contacts, viewing history, comments, analytics or any other personal data.

How the data is used

The permissions are used only to publish the owner's own videos, thumbnails and subtitles to the owner's own channel. The data is not used for advertising, profiling or any other purpose.

Storage

The sign-in token is stored only on the owner's own computer, in a file readable only by that user. It is never sent to any server other than Google's.

Sharing

The app does not sell, share or transfer Google user data to anyone. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local token file also stops the app from accessing the account.

YouTube API Services

The app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions about this policy can be sent through the contact details on the What If Thinkers YouTube channel's About page.
